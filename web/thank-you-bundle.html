แนะนำ วิธีเข้าอ่าน ผูกทั้ง 3 เล่มกับบัญชีเดียว
สร้างบัญชีครั้งเดียว ปลดล็อกทีละรหัส แล้วทั้งสามเล่มจะอยู่ในคลังเดียวกัน อ่านได้ทุกอุปกรณ์
1
กด "คัดลอกรหัสทั้ง 3 เล่ม" เก็บไว้ก่อน
หรือจะคัดลอกทีละเล่มตอนปลดล็อกก็ได้
2
สร้างบัญชี หรือเข้าสู่ระบบ
ไปที่ /account สมัครด้วยชื่อผู้ใช้ + รหัสผ่าน (ไม่ต้องใช้อีเมล)
3
เมนู "เพิ่มหนังสือ" → วางรหัสเล่มแรก → ปลดล็อก
ทำซ้ำกับรหัสเล่มที่ 2 และ 3 ใช้เวลาไม่ถึงนาที
4
ครบทั้ง 3 เล่มในคลังเดียว อ่านได้ตลอดชีพ
มือถือ แท็บเล็ต คอม เปิดอ่านได้ทุกที่ที่ล็อกอินบัญชีเดียวกัน 🎉
สร้างบัญชี & ปลดล็อก → ไปที่คลังหนังสือ
ทางเลือก: ใส่โค้ดที่หน้าหนังสือแต่ละเล่ม
เปิด /vol1 /vol2 /vol3 → เลื่อนลงล่างสุด → วางรหัสของเล่มนั้นในช่อง "มี Unlock Code แล้ว?" วิธีนี้จะผูกกับอุปกรณ์ (สูงสุด 2 เครื่องต่อ 1 โค้ด) แนะนำให้ใช้แบบผูกบัญชีจะสะดวกกว่า
เงื่อนไขการใช้งาน
  • แต่ละ Unlock Code ผูกได้กับ 1 บัญชีเท่านั้น เมื่อปลดล็อกเข้าบัญชีแล้วจะผูกถาวร
  • ถ้าเลือกใช้แบบไม่ผูกบัญชี (ใส่ที่หน้าหนังสือ) 1 โค้ดใช้ได้สูงสุด 2 เครื่อง; เครื่องที่ 3 จะดันเครื่องเก่าสุดออกอัตโนมัติ
  • สิทธิ์อ่านตลอดชีพทั้ง 3 เล่ม ไม่มีวันหมดอายุ ตราบที่ระบบยังให้บริการ
  • เนื้อหามีลิขสิทธิ์ ห้ามคัดลอก เผยแพร่ซ้ำ แชร์ หรือขายต่อ Code/เนื้อหา ระบบมีการติดตามการใช้งานผิดปกติ
  • เป็นสินค้าดิจิทัลที่ส่งมอบทันที ขอสงวนสิทธิ์ไม่คืนเงิน หลังเปิดใช้โค้ดแล้ว
