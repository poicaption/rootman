# เสร่อศาสตร์

> ศาสตร์แห่งการกล้าเข้าไปอยู่ในพื้นที่ของโอกาส ก่อนที่จะมีใครออกบัตรเชิญให้เรา

หนังสือที่ฉีกออกมาจากซีรีส์ **Root of** — ไม่ใช่หนังสือปลุกใจ ไม่ใช่หนังสือสอนให้ไร้มารยาท แต่เป็นคู่มือสำหรับคนมีความสามารถที่กำลังถูกความอาย ความเกรงใจ และการรอคอยกดเอาไว้

## โครงสร้างมาตรฐานทุกบท

1. **เรื่องเปิดบท** — เหตุการณ์หรือเรื่องเล่าที่ทำให้เห็นปัญหา

3. **คำอธิบายทางจิตวิทยาและพฤติกรรม**
4. **เสร่อแบบผิด กับเสร่อแบบถูก**
5. **สถานการณ์ใช้งานจริง** — งาน ธุรกิจ เงิน ความสัมพันธ์

7. **แบบฝึกหัดท้ายบท** — ลงมือทำภายใน 24 ชั่วโมง
8. **ประโยคจำของบท** — หนึ่งประโยคที่แชร์บนโซเชียลได้
